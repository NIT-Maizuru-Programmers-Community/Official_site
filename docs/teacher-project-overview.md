# 先生への説明資料：プログラマーズコミュニティ部 公式サイト

> 説明用のたたき台です。学校・部活動の確認状況や運用体制は、関係者への確認に応じて更新してください。

## まず伝えること

舞鶴高専プログラマーズコミュニティ部の活動、作品、大会実績、お知らせを紹介する公式サイトを、部員がGitHub上で協力して開発・更新しています。サイトの公開を通じて、部の活動を学内外へ分かりやすく伝え、入部や見学を考える人が情報を得られるようにすることが目的です。

## サイトで紹介する内容

- 競技プログラミング、Web・アプリ開発、チームでの制作
- 部員が制作した作品と、大会・イベントの実績
- 部からのお知らせ、学校や関連団体へのリンク
- 入部・見学を検討する人向けの案内

## 仕組み

- Next.js・React・TypeScriptを使い、サイトを静的なHTML等に生成します。
- Cloudflare Workers Static Assetsで静的なサイトを配信する構成です。
- ログイン機能、独自データベース、独自のお問い合わせ送信機能はありません。
- 掲載内容はリポジトリ内のデータを部員が更新し、確認後に再生成・配信します。
- GitHubのPull Requestで変更を確認し、自動チェックと別の部員のレビューを通してから`main`へ取り込みます。

## 公開に関する現在の状態

サイトは [https://www.programmerscommunity.tech/](https://www.programmerscommunity.tech/) で公開済みです。現在のデプロイ方法や運用体制の詳細は、担当者に確認します。

引き続き確認・整理する項目は次のとおりです。

- 学校・部活動として公開してよい範囲、公開責任者、更新・承認の流れ
- 部の正式な活動日時・場所・問い合わせ窓口（現在は準備中の案内）
- 写真・作品・大会実績・個人名を掲載する許可と内容の正確さ
- Cloudflareのアカウント・公開設定とデプロイ方法
- プライバシーポリシー表記と情報更新担当

未確定の情報を推測で埋めず、承認済みの情報だけを載せます。現在、お問い合わせ情報をこのサイトで収集・保存する設定はありません。将来フォーム等を導入する場合は、利用サービス・目的・保存期間を決めて表示を更新してから受付を始めます。

## 説明用の話し方（約2分）

「プログラマーズコミュニティ部の活動を、入部や見学を考えている学生や、学校内外の方に知ってもらうための公式サイトを公開しています。競技プログラミング、Web・アプリ開発、作品、大会実績、お知らせなどを紹介します。

サイトはNext.jsなどで静的なページとして生成し、Cloudflare Workers Static Assetsで配信する構成です。ログインや独自データベースはなく、現在はこのサイト内で問い合わせ情報を集める機能もありません。部員がGitHubで内容を更新し、Pull Requestのレビューと自動チェックを通してから反映します。

今後の運用に向けて、学校・部活動としての確認事項、活動情報、問い合わせ方法、写真や個人名の掲載許可、更新責任者を整理したいです。公開してよい情報の範囲と更新手順についてご相談させてください。」

## 先生に相談・確認したいこと

1. 現在の公開について、学校の確認や申請手続きが必要でしょうか。
2. 公開先やドメイン、管理について、学校の指定やルールはありますか。
3. 活動日時・場所・問い合わせ窓口は、どの情報を掲載すればよいでしょうか。
4. 部員の写真、氏名、作品、大会実績を掲載するときの許可・確認手順はありますか。
5. 内容の最終確認者と、公開後の更新担当者をどのように決めるのがよいでしょうか。

## よく聞かれそうなこと

**Q. もうインターネットで公開されていますか？**  
A. はい。[公式サイト](https://www.programmerscommunity.tech/)を公開しています。学校側の確認事項と運用体制は関係者に確認します。

**Q. 問い合わせフォームから個人情報を集めますか？**  
A. 現在、サイト独自のお問い合わせ送信機能はなく、このサイトでは問い合わせ情報を収集・保存していません。窓口を設ける場合は、利用サービスや保存期間を先に決めて案内します。

**Q. 情報は誰が更新しますか？**  
A. 部員がリポジトリ上で変更案を作成し、レビューと自動チェックを通した変更を反映します。最終確認者と更新担当者は関係者に確認します。

**Q. 更新時には何を確認しますか？**

A. 学校・部活動として必要な確認、掲載情報の正確さ、写真・氏名等の掲載許可、問い合わせ方法、プライバシー表記、公開先での表示を確認します。
